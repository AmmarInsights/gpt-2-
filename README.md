# gpt-2-
A GPT-2 style language model with **grouped-query attention (GQA) and a byte-level BPE tokenizer written from scratch, trained on Tiny Shakespeare. Runs on a free Google Colab GPU.  It follows the recipe from Andrej Karpathy's Let's reproduce GPT-2 (124M) code-along (pre-LayerNorm blocks, GELU(tanh) MLP, learned position embedding
